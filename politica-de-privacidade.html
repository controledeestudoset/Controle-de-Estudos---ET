Política de Privacidade

Controle de Estudos - ET · Última atualização: 16/11/2026

Resumo

Este programa é um planejador de estudos que roda inteiramente no seu navegador. O autor do programa não recebe, não vê e não guarda os seus dados. Não há servidor, cadastro, anúncios nem ferramentas de rastreamento.

Onde ficam os seus dados

Os dados que você registra (estudos, ciclo, planejamento, revisões, anotações) ficam no armazenamento do seu próprio navegador, no aparelho que você usa.

Sincronização opcional com o Google Drive

Se você escolher Entrar com Google, o programa pede permissão para acessar apenas a pasta privada do aplicativo no seu Google Drive (permissão drive.appdata). Com ela:

  • o programa cria e atualiza um único arquivo (estudo-total-dados.json) nessa pasta, que fica escondida e é separada dos seus arquivos comuns;
  • ele não consegue ver, listar ou alterar nenhum outro arquivo do seu Drive;
  • o arquivo fica na sua conta e o envio sai direto do seu navegador para o Google, sem passar por nenhum servidor do autor;
  • o programa não lê o seu nome, e-mail, contatos ou qualquer outro dado da conta Google.

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado: os dados são usados apenas para sincronizar o seu plano entre os seus aparelhos, não são transferidos a terceiros e não são usados para publicidade.

Como parar ou apagar

  • Em Sincronizar › Desligar, o programa para de enviar dados e revoga o acesso neste aparelho. Os dados continuam no aparelho.
  • Para remover o acesso e o arquivo da nuvem, abra myaccount.google.com/permissions, escolha o aplicativo e remova o acesso e os dados dele.
  • Para apagar os dados do aparelho, use Zerar tudo em Exportar planilhas, ou limpe os dados do site no navegador.

Cookies e terceiros

O programa não usa cookies de rastreamento. Ele carrega, de servidores públicos de bibliotecas, a biblioteca de planilhas (SheetJS) e, só ao entrar com Google, o script de login do Google.
